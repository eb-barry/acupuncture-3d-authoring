# 經絡製圖室 Meridian Studio

以 Three.js、Vite 與 Vanilla JavaScript 製作的瀏覽器 3D 經脈編輯器。所有模型與標註只在本機瀏覽器處理。

## 功能

- 載入或拖放 MakeHuman／Blender 匯出的二進位 GLB，並自動置中、縮放
- 預載以 Blender 清理重疊面、法線及正面皺褶後的成人體表模型
- OrbitControls 旋轉、平移與縮放
- 使用完整 361 穴位目錄，先依十四經脈篩選，再按國際代碼數字排序
- 十二正經自動建立不可解除的左右穴位與路線配對；任督二脈使用中線單點（不強制鎖到模型幾何中心）
- 穴位標記、紅藍綠配色及貼膚中文名稱標籤
- 經脈與穴位以貼皮方式繪製：取樣點全部投影到網格表面，線帶躺在皮膚切平面內，
  靠深度偏移而非法線位移取得可見度，因此旋轉、放大、縮小都不會浮在皮膚上方
- 貼皮渲染可調整經脈線寬（mm）、穴位直徑（mm）與離皮位移（mm，預設 0 可與舊版比對），
  這些只影響畫面，不寫入 JSON
- 貼合皮膚的可調曲線與可拖曳控制點
- 右側以 checkbox 複選要顯示在 3D 模型上的經脈／穴位；不影響左方編輯經脈與新增穴位
- 經脈顏色為全域設定：任督二脈藍、陰經綠、陽經紅
- 完成所選經脈全部穴位定位後，依國際代碼順序逐點繪製路線
- 編輯、刪除、Undo／Redo 及鍵盤快捷鍵
- 依 JSON Schema v2 驗證、匯入與匯出穴位配對及完整經脈路線
- GitHub Actions 部署至 GitHub Pages

## 開發

```bash
npm install
npm run dev
```

執行測試與正式建置：

```bash
npm test
npm run build
```

## 操作

1. 編輯器會自動載入成人體表模型並顯示進度；也可按「載入 GLB」或將自己的 `.glb` 拖入畫布。
2. 先選擇經脈，再從依國際代碼排序的目錄選取穴位。
3. 十二正經選擇首次定位側別後，用「穴位」工具點擊皮膚，另一側會自動鏡射並鎖定。
4. 匯入含多條經脈的 JSON 後，可在右側以 checkbox 複選要顯示的經脈／穴位；左方仍可繼續編輯其他經脈。
5. 完成該經脈全部穴位定位後，「顯示經脈」會依右側勾選經脈顯示連線；顯示中仍可定位新穴位，並可拖曳已定位紅點調整位置。
6. 繪製中或完成後皆可點擊線段插入控制點；選取路線後拖曳金色控制點調整曲度。
7. 從右側清單調整紅藍綠配色，以及貼皮渲染的經脈線寬、穴位直徑與離皮位移。編輯時若穴位或黑點被皮膚遮住，可勾選「編輯透視」；拖曳中會自動透視。選取穴位後按頂部工具列「刪除」（或 Delete 鍵）移除，Ctrl/⌘+Z 復原。
8. 「驗證」檢查目前文件；「匯出」下載可再次匯入的 JSON。

GLB 本身不會嵌入匯出的標註 JSON；再次編輯時應先載入相同模型。模型在載入時會正規化至三個場景單位高，因此標註座標可在同一模型上重現。

預設人體模型及穴位資料的授權、來源、修改方式與檔案雜湊記錄於
[`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md)。模型可作為體表視覺與標註基礎，
但不應視為經臨床驗證的醫療診斷模型。
